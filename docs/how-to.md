# How-To Guide

## Basic Usage

### Opening PiNGiN

1. Press `Ctrl+Shift+P` (or your configured shortcut)
2. PiNGiN captures your context (window title, selected text, browser URL, screenshot)
3. The companion window appears at your cursor position
4. Your context is automatically sent as the initial prompt

### Sending Messages

1. Type your message in the input field at the bottom
2. Press `Enter` to send (or `Shift+Enter` for a new line)
3. Responses stream in real-time

### Aborting a Response

While the agent is streaming, click the ✕ button in the title bar or the red button in the input area.

## Context Capture

### Capturing Selected Text

1. Select text anywhere on your screen
2. Press the PiNGiN shortcut
3. The selected text is captured and sent as part of the initial prompt

### Capturing a Screen Region

1. Press `Ctrl+Shift+M` (or your configured mark shortcut)
2. PiNGiN marks the region for capture
3. Press the PiNGiN shortcut to capture the marked region

### Customizing Context Capture

In the hamburger menu, you can disable individual capture types:

- **Window title** — the active window's title
- **Selected text** — currently selected text
- **Browser URL** — the current URL in your browser
- **Screenshot** — a screenshot of your screen

## Session Management

### Switching Models

1. Open the hamburger menu (☰ button)
2. Click "Model" to see available models
3. Select a model

### Changing Thinking Level

1. Open the hamburger menu
2. Click "Thinking Level"
3. Select from: `off`, `minimal`, `low`, `medium`, `high`, `xhigh`

### Managing Sessions

1. Click the clock icon in the context pill to open session history
2. **Cursor sessions** (purple) are inline sessions
3. **Background sessions** (grey) are spawned separately
4. Click a session to resume it
5. Click the trash icon to delete a session

## Themes

Switch themes via the hamburger menu → Theme:

- **Slate Red** — red accent color
- **Slate Blue** — blue accent color
- **Slate Green** — green accent color
- **Slate Purple** — purple accent color

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Ctrl+Shift+P` | Open PiNGiN |
| `Ctrl+Shift+M` | Mark screen region |
| `Escape` | Hide PiNGiN window |
| `Enter` | Send message |
| `Shift+Enter` | New line in input |
